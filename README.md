# Навигатор образовательных курсов Пермского края

Готовый статический сайт на HTML, CSS и JavaScript. Данные — 142 записи из уточнённого пользователем листа «Итог». Сверка публичных полей выполнена без изменения их содержания.

## Загрузка на хостинг

1. Распакуйте `navigator-perm-site.zip`.
2. Загрузите всё содержимое архива в папку сайта на хостинге, сохраняя папки `assets` и `data`.
3. Откройте адрес этой папки через HTTPS. Главный файл — `index.html`.

Сайт работает как в корне домена, так и в подпапке, например `/courses/`. PHP, база данных, npm, сборка и настройка перенаправлений не нужны. HTTPS нужен для штатного копирования ссылки; при его отсутствии есть поле для ручного копирования.

## Файлы

- `index.html` — каталог и избранное.
- `course.html?id=PRG_0001` — подробная страница программы с собственной ссылкой.
- `about.html` — информация о проекте.
- `data/catalog.json` — единственный источник данных для сайта.
- `assets` — стили, JavaScript, локальные шрифты, логотип и лицензия шрифта.

Excel в архив не входит. JSON является публичными данными, которые браузер загружает для показа карточек. Внутренние замечания, журнал исправлений и сведения о грантовых кандидатах в него не включены.

## Проверка на компьютере

Открытие двойным щелчком (`file://`) не поддерживается, поскольку браузеры ограничивают загрузку JSON. Запустите HTTP-сервер в папке сайта, например `python -m http.server 8000`, и откройте `http://localhost:8000`.

## Обновление каталога

Замените `data/catalog.json` файлом той же структуры. Сохраняйте ID существующих программ: они используются в ссылках и избранном. Счётчики тем и варианты фильтров формируются из JSON автоматически. Для каждого нового тематического направления нужна запись в массиве `topics`.

После обновления проверьте несколько карточек и очистите серверный/CDN-кеш JSON, если он включён. При настройке собственного кеширования рекомендуются короткий срок или перепроверка версии для JSON и HTML.

## Поведение каталога

Тема выбирается одна. Значения внутри одного фильтра объединяются по «ИЛИ», разные фильтры — по «И». Количество у каждого варианта учитывает другие фильтры. Неизвестная стоимость не считается бесплатным участием. Программы с альтернативами «онлайн; очно» находятся в обоих форматах, а обязательное смешанное обучение — отдельный формат.

Фильтры сохраняются в адресной строке. Избранное хранится только в localStorage текущего браузера. При запрете хранения избранное работает до закрытия страницы; уведомление появляется после попытки сохранения. Сайт не отправляет эти данные на сервер. Обратная связь и заявки направляются через сайты организаторов; скрытой формы отправки нет.

Статус проверки не используется для повторного исключения вручную отобранных пользователем карточек. Текст актуальности и условия перенесены из таблицы; сайт не подтверждает свободные места и не переносит даты потоков автоматически.

## Оформление

Использованы палитра и логотип из предоставленного брендбука ГРАНИ, гарнитура Clear Sans (локальные файлы; лицензия в `assets/ClearSans-LICENSE.txt`). Внешние библиотеки, шрифтовые сервисы и аналитические счётчики при открытии сайта не загружаются.

## Выполненные проверки

Публичные поля JSON сверены с 142 строками уточнённого листа. В браузере проверены темы, объединение типов по «ИЛИ», пересечение с режимом, восстановление фильтров после перезагрузки, русский поиск, пустая выдача, показ следующих 12 карточек, сохранение избранного, подробная страница, возврат к отфильтрованной выдаче и рекомендации. Проверена адаптивная компоновка в области шириной 390 px и фильтр бесплатного обучения: 47 программ. Проверка выполнена в Chromium; отдельные испытания на физических iPhone/Android не проводились.
